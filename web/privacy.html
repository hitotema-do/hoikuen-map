プライバシーポリシー

名前や連絡先は集めていません

このアプリは登録なしで使えます。名前、住所、メールアドレス、お子さんの情報などを入力していただくことはありません。

現在地の使い方

現在地は、地図の「現在地を表示」ボタンを押したときだけ、ブラウザの機能で取得します。はじめて押したときは、お使いのスマホやパソコンから許可を求められます。

取得した現在地は、地図をその場所へ動かすことと、「近い順」の距離を計算することに使います。運営者には送られず、保存もしません。ページを閉じると消えます。

お使いの端末の中だけに保存するもの

次の内容は、お使いのスマホやパソコンの中だけに保存し、運営者には送られません。

  • 1日に1回だけ数えるための、最後に数えた日の記録
  • 下の方法で数え方を止めた場合は、その設定

選んだ年齢、区や種類の絞り込み、検索した園の名前は保存しません。すべて消すには、ブラウザの設定でこのサイトのデータを削除してください。

利用状況の調べ方

どれくらい使われているかを知るため、次の2つの方法で調べています。どちらも、個人を特定するためのものではありません。

1. 1日に何台から開かれたかを数える
1台につき1日1回、数を増やすための通信をします。送るのは、アプリの名前、はじめての利用かどうか、その週はじめての利用かどうか、どのサイトやチラシから来たかです。名前や端末を見分ける番号は送りません。

このリンクを開くと、お使いの端末ではこの数え方を止められます（元に戻す）。

2. Cloudflare Web Analytics
ページの表示回数、どのサイトから来たか、ブラウザの種類などの統計を見ています。取り扱いはCloudflareのプライバシーポリシーをご覧ください。

外部のサービス

このアプリの配信に GitHub Pages、地図の表示に国土地理院の地図と cdnjs、運営情報のページの文字の表示に Google Fonts、利用状況の集計に Cloudflare を使っています。通信の仕組み上、IPアドレスやブラウザの種類などは、これらの提供元に届きます。

地図を表示するため、画面に映っている場所の地図画像を国土地理院から読み込みます。

お問い合わせについて

お問い合わせには Google フォームを使っています。名前や連絡先の欄は設けておらず、メールアドレスも集めません。本文にも個人情報は書かないでください。
